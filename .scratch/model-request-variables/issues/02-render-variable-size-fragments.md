# 02 — 在 User 轨道展示变量大小片段

Status: resolved

## What to build

模型请求轨迹的请求组成图需要把每个已观察模型请求变量按其实际展开文本大小拆成独立片段，并放入 User 轨道。变量片段应像每个工具定义片段一样独立可见、可点击，同时不得重复计入请求组成总字符数。

## Acceptance criteria

- [x] 每个非空、已观察变量在 User 轨道中对应一个独立片段
- [x] 变量片段大小使用模型请求证据范围的实际字符数
- [x] 原消息片段按变量范围拆分，组成总字符数不重复计算
- [x] 点击变量片段能够选中对应 VARIABLE 轨迹行
- [x] 单请求与完整会话组成图都支持变量片段
- [x] 相关测试、类型检查和客户端构建通过

## Comments

变量片段统一投影到 User 轨道，满足轨道展示要求；原消息中的对应字符会被扣除，因此总字符数不会重复。变量片段使用 `variable:<id>` 作为点击定位身份，并用 `variableId` / `variableName` 标记视觉样式和提示信息。
