# 04 — 折叠历史消息变量预览

Status: resolved

## What to build

模型请求分析页中，`history_new` 与 `history_last` 的格式化消息预览在内容较长时默认折叠，避免历史消息占满变量区。折叠区底部提供与长文本一致的“展开全部（N 字符）”控制，展开后可以再次收起。

原始 XML 切换和变量卡片整体折叠保持独立；切换原始 XML 后再返回格式化预览时，格式化预览的展开状态不应丢失。

## Acceptance criteria

- [x] `history_new` 与 `history_last` 的格式化预览超过默认高度时默认折叠
- [x] 控制文案显示原始变量值字符数，并支持展开和收起
- [x] 短历史预览不显示无意义的折叠控制
- [x] 原始 XML 切换与变量卡片折叠行为保持不变
- [x] 被引用消息正文完整换行展示，不使用聊天气泡的一行省略样式
- [x] 相关测试、类型检查通过

## Comments

参考图中的交互文案为“展开全部（12500 字符）”并带向下箭头。本实现复用分析页长文本折叠的视觉语义，但对结构化历史预览按渲染高度测量，而不是按 XML 行数裁切。

默认折叠高度为 420px；只有结构化预览实际超过该高度时才显示控制。字符数使用模型请求变量的原始观察值长度，确保格式化展示仍与原始证据计数一致。

被引用消息在普通聊天气泡里使用单行省略摘要，但模型请求历史是证据阅读视图，因此为历史预览覆盖为完整换行正文，不再显示省略号。已通过 `tests/model-request-analysis.test.ts`、`tests/model-request-history.test.ts` 与 `yarn typecheck`。
