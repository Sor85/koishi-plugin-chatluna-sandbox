# 01 — 派生并展示模型请求变量

Status: resolved

## What to build

从模型请求关联的运行时预设快照解析预设编辑器高亮的值表达式，复用预设证据匹配算法读取本次模型请求中的观察值。分析页左侧增加 Variables 变量名列表，右侧增加变量值卡片。

## Acceptance criteria

- [x] 变量集合来自运行时预设快照中的值表达式
- [x] 控制标签不进入变量列表
- [x] 左侧 Variables 列出变量表达式名并可定位
- [x] 右侧变量卡片显示来源预设和观察值
- [x] 未观察或歧义表达式不伪造值
- [x] 不采集或持久化整份 before-chat 变量对象
- [x] 相关测试、类型检查和构建通过

## Comments

最初误将需求理解为展示整份 `before-chat` 变量对象；根据截图和补充说明，已撤回该模型。最终实现以预设编辑器高亮的表达式为变量来源，以模型请求证据范围为变量值来源。
