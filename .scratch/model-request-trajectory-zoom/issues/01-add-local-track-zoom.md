# 01 — 增加请求组成轨道局部缩放

Status: resolved

## What to build

请求组成轨道以当前宽度作为 100% 最小缩放，提供放大、缩小和复位控件。放大后轨道内容横向扩展并可滚动，不放大整个页面。

鼠标位于请求组成轨道内容区域时，`Ctrl + 鼠标滚轮` 调整轨道缩放并保持指针下的内容位置；仅此区域阻止浏览器默认页面缩放，其他页面区域继续使用浏览器默认行为。

## Acceptance criteria

- [x] 当前轨道宽度是最小 100%，不能继续缩小
- [x] 提供轨道右上角覆盖式放大、缩小和复位控件，不单独占行
- [x] 放大后轨道横向扩展，可滚动并可按住鼠标左右拖动
- [x] 仅轨道内容区域响应 Ctrl + 鼠标滚轮并调用 preventDefault
- [x] 缩放时尽量保持鼠标指针下的内容位置
- [x] 普通滚轮和轨道外 Ctrl + 滚轮不被拦截
- [x] 相关测试、类型检查和客户端构建通过

## Comments

缩放范围为 100%–1000%，每步 25%。Ctrl + 滚轮监听器只挂在轨道内容 viewport 上，非 Ctrl 滚轮立即返回；因此只有指针位于该区域并按住 Ctrl 时才阻止浏览器默认缩放。按钮缩放以 viewport 中心为锚点，滚轮缩放以鼠标横坐标为锚点。缩放控件覆盖在原轨道右上角，倍率位于最左侧，界面不再显示快捷键说明；viewport 使用 Pointer Capture 支持鼠标左键拖拽平移，超过 3px 才进入拖拽并抑制随后的片段点击，拖拽区域不改变鼠标指针样式。
