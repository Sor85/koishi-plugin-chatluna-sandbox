# 04 — 恢复发送焦点并移除禁止光标

**What to build:** 保持现有单请求发送锁，在发送结束后可靠恢复消息输入焦点，并统一调整发送区域禁用光标。

**Blocked by:** 无

**Status:** ready-for-agent

- [ ] textarea 使用稳定 ref，发送成功和失败后在 `nextTick` 恢复焦点
- [ ] 只有原会话、原操作者和原输入控件仍有效时才恢复焦点
- [ ] 发送中继续阻止重复提交，不新增消息队列
- [ ] 输入框、附件、表情和发送按钮禁用时均不显示 `not-allowed` 光标
- [ ] disabled 和透明度仍清楚表达不可操作状态
- [ ] 覆盖连续“输入—回车—输入—回车”、失败、切换会话和组件卸载测试
- [ ] 使用 Ego Browser 验证 Chrome、Firefox 和键盘连续发送
