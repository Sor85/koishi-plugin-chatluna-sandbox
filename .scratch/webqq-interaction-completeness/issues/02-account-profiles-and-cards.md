# 02 — 建模账号资料并增加个人信息卡

**What to build:** 扩展普通用户和虚拟 OneBot 机器人的类型化账号资料，补齐个性签名读写和 OneBot 回读，并为所有参与者头像提供统一个人信息卡。

**Blocked by:** 无

**Status:** ready-for-agent

- [ ] 账号资料、好友备注、群成员资料和机器人运行资料使用独立类型
- [ ] 覆盖当前 NapCat/LLOneBot 基线可表达的类型化可选字段，不保存 raw JSON
- [ ] `set_qq_profile` 支持昵称和个性签名，并严格保留性别写入差异
- [ ] 对应 OneBot 查询返回已建模资料，字段名按实现配置映射
- [ ] 环境管理、MCP 场景准备、导入导出和数据库持久化支持新增资料
- [ ] 私聊右侧信息面板显示个性签名
- [ ] 消息、私聊头部、好友列表和群成员列表头像右键可打开个人信息卡
- [ ] 卡片显示场景全部资料并标明账号、好友、群成员和机器人范围
- [ ] 使用 Ego Browser 验证 Chrome、Firefox、窄屏和 Portal 主题样式
