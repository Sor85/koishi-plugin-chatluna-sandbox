# 07 — 聊天记录搜索编排下沉

**What to build:** 聊天记录搜索的整条流程变成可以不起组件就逐条驱动的模块，三个巨型用例按主题拆开。

今天这条流程完全住在聊天区域的 `script` 里：发起查询、按条件（关键词与按本地日历日的日期范围）取结果、翻页取更多命中、点某条命中跳到消息列表里对应那条并高亮、点搜索框外面关闭、关闭后把焦点还回入口按钮。日期换算与「确保目标消息已加载」两块已经是模块，编排没有。

失败时的定位同样成问题：这个测试文件三个用例承载一百三十多条断言，任何一条失败都只报同一个用例名。本票按主题把它们拆开。

界面一字不变。搜索仍然通过消息列表组件已有的对外方法完成跳转，那个方法的签名不动。
