# 02 — 记录域带上记录库，跨记录域读取与轨迹不再穿控制服务

**What to build:** 全部空间视图下读一条记录详情、以及在主模拟 QQ 环境、AI 测试空间、未归属三种来路下读模型请求轨迹，行为一字不变，但路径少一层。

今天这两条路都写成「取记录域 → 取控制服务 → 取记录库 → 读记录」，穿两层去拿；轨迹那条还要按记录来路在三者之间三层嵌套地挑记录库。本票让记录域自己带上记录库——未归属那一支今天已经带了，场景那一支补上——并由记录域目录提供「按记录域标识取记录库」这一件事，那段三元表达式塌成一次查询。

控制服务上取得记录库的入口保留，但从此只服务于插件入口的装配，不再有别的消费方。

那个可辨识联合不动：未归属仍然只有记录库、没有沙盒场景，跨记录域查找仍然只吃场景那一支，「未归属永不参与联邦读取、必须显式指定范围才能读到」一行不改。记录域目录那条 ADR 只补一句形状说明，既有决定一条不推翻。也不要顺手把可选字段换成判空——上一轮明确判过，可选字段只是把判空搬进类型里。

**Blocked by:** None — can start immediately.（与 01 无依赖，但两票改的是同一个详情读取函数的不同分支，推荐在 01 之后做以省一次重复编辑。）

## Comments

### 落地形状

- `SceneScope` 多一个 `records: SandboxModelRequestStore`，与 `UnattributedScope` 同名同义，
  `RecordScope` 两支因此都能直接给出记录库。`control` 原样保留：等就绪、清场景仍归它。
- 记录域目录新增 `getModelRequests(scopeId)`，实现是 `listScopes().find(...)?.records` 一句。
- 跨记录域详情读取（Console 与 MCP 各一处）从 `scope.control.getModelRequestStore().getRecord(...)`
  变成 `scope.records.getRecord(...)`。
- 轨迹那段按来路的三层嵌套三元塌成一次查询：来源标注反过来给出记录域标识
  （`modelRequestScopeId`），记录库按这个标识取一次。三种来路只影响标识的值，不再影响分支数。
- 装配侧同样收敛：`getCandidates` 与用量关联的记录库清单都直接读 `records`；预设服务的
  `getTestSpaceModelRequests` 改成 `scopes.getModelRequests(spaceId)`，原先那段
  `spaceId === 'main' ? … : try { getControl(spaceId).getModelRequestStore() } catch {}` 整段消失。

### 未打勾的那条：取得记录库的入口还有第二类消费方

`control.getModelRequestStore()` 现在有三处调用：记录域目录构造（主环境与测试空间各一处）、
预设服务装配（`mainModelRequests`），以及**单记录域详情读取**两处（Console 的
`resolveModelRequestControl(input)!.getModelRequestStore()`、MCP 的
`resolveControl(args, false).getModelRequestStore()`）。前三处是装配，符合本票的判定。

最后那两处没有改成 `scopes.getModelRequests(...)`，理由是那条路上的控制服务解析不只是「取记录库」：
它同时做空间存在性与权限判定，并按 MCP 的错误码契约抛出结构化错误（`space_id_required`、
空间不存在等）。改成按标识取记录库会跳过这段判定，未知空间会从结构化错误退化成「记录不存在」，
与「对外可观察行为逐字不变」和「控制服务其余职责一律不动」冲突。保留它等于承认这条路上
**先解析出控制服务是权限需要**，取记录库只是解析之后的一步，而不是穿两层去读。

如果要把这条也收掉，正确做法是把「按范围解析出权限已校验的记录库」变成一个独立成员，
那属于「控制服务按职责划内部 module」那条候选的范围，本轮不做。

### 既有决定一条未推翻

- 可辨识联合未改成可选字段：未归属仍然没有 `control`，场景那一支仍然没有 `records?`。
- 未归属仍然不参与联邦读取（`listScenes` 不含它），既有断言「联邦只遍历沙盒场景」一字未改地通过。
- 「未命中返回空值、持久化故障照原样抛出」一字未改，既有断言继续通过。
- ADR-0083 只补一段形状说明，既有段落一字未改。
