# 01 — 回退未定形的领域与 RPC 实现，界面暂不接线

**What to build:** 工作区回到一个自洽、可构建、测试全绿的状态。当前未提交的会话分支实现在领域层与 RPC 层的形状已被规格推翻，这张票把它们清掉，只留下可以复用的界面产物。

根会话类型上新增的父会话字段与标题字段撤掉；分支复制消息的领域方法撤掉；创建会话与创建分支两个 Console 端点及其声明撤掉；客户端工作区端口上的这两个方法、端口适配器里的强制类型转换、控制器上的两个方法、工作台外壳里的两个包装函数一并撤掉。

侧栏会话树的模板与样式、消息右键的「创建分支」菜单项、展开态处理保留在库中，但暂时不接数据源也不发请求——它们在票 03 与票 08 里重新接线。此时侧栏对每个会话都不显示子项。

这张票不引入任何新行为，也不新增测试。它单独成票是因为它会丢弃一部分已写代码，需要单独可见、单独可回退。

**Blocked by:** None — can start immediately

**Status:** ready-for-agent

- [ ] 根会话类型不再带父会话字段与标题字段
- [ ] 领域层不再有创建会话实例与创建分支的方法
- [ ] Console 事件表、模块声明增强、客户端端口、端口适配器、控制器、工作台外壳都不再出现这两个端点
- [ ] 客户端端口适配器里不存在绕过类型检查的强制转换
- [ ] 侧栏会话树组件与样式仍在库中，界面不再显示任何子项，也不发起任何请求
- [ ] `yarn test`、`yarn typecheck`、`yarn build` 全部通过
