# 06 — 插件视角：channel 类型与回复偏离记录

**What to build:** 让被测插件在会话实例里看到的东西是准确的，并且把沙盒无法替它归位的那部分显式变成可断言的证据。

两件事。第一，群组的实例在插件那里仍然是群会话：channel 类型改为从解析出的会话读取，不再靠解析会话 ID 前缀推断——实例 ID 没有群前缀，现在的推断会把群实例判成私聊 channel。

第二，插件用原始 OneBot action 回复时，回复落到根会话。真实 QQ 的 action 表面确实没有「会话」这一级，沙盒不按最近一次事件或异步上下文替插件猜测归位，那会让沙盒行为与真实环境分叉。改为在 OneBot 调试记录里留下一条「回复偏离了事件来源会话」的观察结果，包含事件来源会话与实际落点，供用户复盘和外部测试控制器断言。它是证据，不是警告日志。

**Blocked by:** 03

**Status:** ready-for-agent

- [ ] 群组实例的入站事件在插件侧仍是群会话，私聊实例仍是私聊会话
- [ ] channel 类型来自解析出的会话，源码中不再按会话 ID 前缀推断
- [ ] 插件用原始 OneBot 私聊或群消息发送 action 回复时，消息落到根会话
- [ ] 该情形在 OneBot 调试记录里产生一条可读取、可断言的偏离记录，包含来源会话与实际落点
- [ ] 事件不来自实例时不产生偏离记录
