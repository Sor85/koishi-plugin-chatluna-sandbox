# 04 — 从消息创建分支

**What to build:** 用户在会话里任意一条消息上选择「创建分支」，沙盒新建一个会话实例并把该消息及其之前的历史复制进去，新实例自动选中，默认标题指出它的来源会话。插件在新实例里看到的上下文与原会话在分叉点上一致，因此可以从这里换一种问法而不动原始记录。

复制的消息获得新的消息身份并归属新实例，其中的引用关系在复制范围内重新指向复制体。消息事件（例如戳一戳）不提供创建分支入口。

本票沿用「复制消息」的实现方式。改为只记录分叉点、读取时拼接根会话前缀是明确的范围外工作。

**Blocked by:** 03

**Status:** ready-for-agent

- [ ] 消息右键提供「创建分支」，消息事件类型的消息不提供
- [ ] 新实例包含分叉点及其之前的全部消息，顺序与原会话一致
- [ ] 复制体拥有新的消息身份，归属新实例，复制范围内的引用指向复制体
- [ ] 新实例的默认标题能指出来源会话
- [ ] 创建完成后自动选中新实例
- [ ] 分支端点返回完整工作区状态与新会话 ID，客户端只发一次请求
- [ ] 在分支里发消息时插件看到的上下文包含被复制的历史
