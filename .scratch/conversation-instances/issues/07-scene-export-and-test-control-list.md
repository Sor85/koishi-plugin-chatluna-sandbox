# 07 — 场景导出与测试控制端点的会话列表

**What to build:** 让会话实例在场景导出与外部测试控制器面前的呈现是明确的，不多也不少。

场景导出包含会话实例——导出是整份场景，漏掉实例会让导入回来的场景与原场景不等价。导入一份含实例的场景后实例原样保留，用户准备好的分支因此可以作为测试前置条件。

测试控制端点的会话列表默认只返回根会话，避免外部测试控制器把实例误当成新的联系人；需要观察分支时通过显式参数读取某个根会话下的实例。本票不新增「创建实例」或「分叉」这类写工具。

**Blocked by:** 03

**Status:** ready-for-agent

- [ ] 场景导出包含会话实例及其消息归属
- [ ] 导入导出的场景后实例数量、归属与标题原样保留
- [ ] 测试控制端点的会话列表默认只返回根会话
- [ ] 通过显式参数可以读取某个根会话下的实例
- [ ] 未新增任何允许外部测试控制器创建或分叉实例的工具
- [ ] 默认场景不生成实例
