# 02 — 会话解析 module 与架构守卫（行为不变）

**What to build:** 把「某个会话 ID 指向谁、某个操作者能看到哪些会话、一对参与者或一个群组的会话在哪」这件事收敛成一处答案，外部行为与本票开始前完全一致。

新增一个服务端领域模块，形态是一组接收沙盒场景的纯函数。它吃掉当前散落的解析实现：按参与者对确保私聊会话、按群号确保群会话、按 ID 取可见会话、可见性判定、好友动作与群动作在缺少会话 ID 时的会话查找、事件投递时的会话标识构造、虚拟 OneBot 机器人最近联系人列表的会话来源。解析对外返回一个统一结果，包含会话 ID、是根还是实例、所属根会话 ID、私聊还是群聊、参与者对或群号、消息 ID 列表；此时场景里还没有实例，所有解析结果都是根会话。

同时新增一条架构守卫规则：除该模块外，服务端源码不得直接读写会话集合。已知违规按现有守卫的形状登记为显式豁免，理由与负责消化它的后续工作均为必填，并保持「移除任一豁免后对应文件重新报错」这条自检。

- [ ] 既有测试全部保持通过，没有任何外部行为变化
