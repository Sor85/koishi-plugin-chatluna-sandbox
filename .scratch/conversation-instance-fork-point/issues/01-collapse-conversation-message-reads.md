# 01 — 把会话消息列表的读取收成一个入口（行为不变）

**What to build:** 让「某个会话的消息列表」在服务端只有一个读取入口，为后续的拼接留出唯一落点。本票不改变任何外部行为。

现在会话解析结果对外暴露的是对场景里那个消息 ID 数组的实时引用（为热路径省一次复制），调用方直接对它取长度、找下标、切片。拼接之后这个引用无法表达合成出来的列表，因此先把读取收成会话解析模块里的一个函数，再让全部调用方经它读取：消息历史分页、消息搜索、可见快照投影、OneBot 侧的消息读取与历史、清空会话、测试控制端点的会话读取。

收敛时要逐处确认没有调用方依赖那个数组对象的身份不变——保留窗口摘除引用时会替换整个数组，长期持有解析结果的代码本来就不该假设身份稳定。

此时该函数返回的就是原来那份列表，既有测试全部保持通过。

**Blocked by:** None — can start immediately

**Status:** ready-for-agent

- [ ] 会话解析模块提供唯一的「读某个会话的消息列表」函数
- [ ] 解析结果不再对外暴露对场景消息 ID 数组的实时引用
- [ ] 消息历史分页、消息搜索、可见快照投影、OneBot 消息读取与历史、清空会话、测试控制端点的会话读取全部经该函数
- [ ] 没有任何调用方依赖消息 ID 数组对象的身份不变
- [ ] 既有测试全部通过，外部行为零变化
