# 06 — 分叉点术语与 ADR

**What to build:** 把「分支只记分叉点、读取时拼接」这件事写进仓库的领域记录，并交代它与上一轮那条 ADR 的关系。

领域词汇新增「分叉点」条目：会话实例记录的来源消息，它界定继承前缀的范围；同时说明应避免的替代叫法（起点、锚点、基线、分支点快照）。

新增一条 ADR 说明分支改为只记分叉点，覆盖三个决定：只存分叉点而不存前缀消息 ID 快照（消息只追加，两者在正常路径上等价，少一份状态就少一处失真）；继承前缀在分支视图里只读但消息实体的生命周期不冻结（区分「用户在对照组里的操作入口」与「消息本身能不能变」）；来源可以是另一个实例、读取时沿来源链拼接而存储仍是两层。

在 ADR-0076 中标注「代价是分支要复制分叉点之前的消息，场景消息保留窗口的预算因此按分支数被摊薄」那一段被本 ADR 取代，不改写 ADR-0076 原文——记录当时为什么接受复制这个取舍本身有价值。
