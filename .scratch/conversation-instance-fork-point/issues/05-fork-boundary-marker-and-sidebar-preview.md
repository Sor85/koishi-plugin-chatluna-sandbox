# 05 — 分界标记与侧栏预览

**What to build:** 用户一眼看出分支里哪一段是与原会话共享的对照区、哪一段是自己的实验区，并且刚创建的分支在侧栏里不像个空会话。

分支的消息列表在继承前缀与自有消息之间显示一条分界标记，继承部分视觉上稍作弱化。分界同时承担解释职责：它说明上面那段是与原会话共享的同一份记录，因此右键项变少不再像缺陷。继承部分不折叠、不默认收起——看全上下文正是复盘时要做的事。

侧栏会话实例子项的预览取拼接后的最后一条消息，刚创建的分支因此显示分叉点那条，而不是空白。

完成后单独跑一次浏览器实测：确认分界标记在 Firefox 与 Chrome 下呈现一致、向上加载更早消息能连续跨过分界，并按项目约定关闭本次验证打开的浏览器会话、清理浏览器工具生成的临时目录。
