# 04 — 插件视角的继承前缀

**What to build:** 被测插件在分支里看到和读到的东西是准确的，而且沙盒不对它表现出真实环境不存在的错误。

插件在分支里收到事件后，按消息 ID 读取一条继承前缀应当成功：单条消息读取的可选会话校验从「等于消息实体的会话」放宽为「在插件请求的那个会话里可读」。输出的私聊或群聊类型与群号仍由消息实体的会话解释——实例的类型与群号继承根会话，两者结果相同，因此不产生可观察差异；群分支里继承前缀仍然是群聊。

插件通过原始 OneBot 撤回或贴表情作用到一条继承前缀时允许执行：它寻址的是根会话里的一条普通消息，拒绝会让沙盒行为与真实环境分叉。执行后分支里那条随之显示为已撤回——它本来就是同一条消息。

插件读历史时的游标语义与根会话一致，不需要区分会话种类。

**Blocked by:** 02

**Status:** ready-for-agent

- [ ] 插件在分支里按消息 ID 能读到继承前缀
- [ ] 群分支里继承前缀的私聊或群聊信息仍是群聊，群号正确
- [ ] 插件通过原始 OneBot 撤回一条继承前缀时操作生效
- [ ] 该消息在分支里随之显示为已撤回
- [ ] 插件在分支里读历史使用与根会话相同的游标语义，能连续读到继承部分
