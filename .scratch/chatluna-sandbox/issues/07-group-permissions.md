# 07 — 支持群组申请与角色权限操作

**What to build:** 当前用户可以执行群组加入、邀请、退出及管理操作，系统按群主、管理员和普通成员的真实权限决定结果。成功操作会修改共享场景并向相关虚拟机器人产生对应 OneBot 事件。

**Blocked by:** 06 — 支持好友关系、申请与戳一戳

**Status:** ready-for-human

- [x] 用户可以申请加入群组，普通用户和机器人分别通过各自入口处理申请
- [x] 有权用户可以邀请普通用户或机器人入群，邀请保持待处理直到接收方决定
- [x] 群成员可以主动退群并产生可观察事件
- [x] 管理员和群主可以踢出权限允许的成员，普通成员执行相同操作会失败
- [x] 群主可以设置或取消管理员，管理员不能修改群主权限
- [x] 成员可以修改自己的群名片，有权管理者可以修改允许管理的成员群名片
- [x] 有权用户可以修改群名称并向相关机器人产生群资料更新事件
- [x] 群内戳一戳、右键二级菜单和禁用原因在 WebQQ 中可操作且可理解
