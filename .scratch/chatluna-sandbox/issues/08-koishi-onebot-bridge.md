# 08 — 打通标准 Koishi 与 OneBot 机器人闭环

**What to build:** 让虚拟 OneBot 机器人同时成为可供被测插件使用的标准 Koishi Bot 和 OneBot 行为提供者。用户消息、关系和群组操作产生正确 Session 与原始事件；插件调用常用机器人能力后会修改同一模拟 QQ 环境并反馈到 WebQQ。

**Blocked by:** 05 — 支持富媒体消息与安全媒体存储；06 — 支持好友关系、申请与戳一戳；07 — 支持群组申请与角色权限操作

**Status:** ready-for-human

- [x] 虚拟机器人以正确平台、self ID 和状态注册到 Koishi
- [x] 私聊、群聊、通知、申请和成员变化生成标准 Koishi Session
- [x] 同一行为同时提供与实现配置匹配的 OneBot 原始事件数据
- [x] 被测插件发送消息、处理申请和执行常用群管理 action 后会更新共享场景
- [x] 插件调用机器人资料能力时可以修改自身昵称和头像
- [x] WebQQ 与被测插件观察到的用户、关系、消息和机器人资料保持一致
- [x] 操作者不能从 WebQQ 或环境管理入口直接代替机器人执行 action
- [x] 常用运行状态探测 action 返回稳定且可测试的结果
