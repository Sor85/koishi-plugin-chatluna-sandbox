# 06 — 支持好友关系、申请与戳一戳

**What to build:** 当前用户可以通过 WebQQ 右键二级菜单发起和管理好友侧 QQ 行为，包括好友申请、审批、删除好友、好友备注和戳一戳。发给虚拟 OneBot 机器人的申请必须等待被测插件处理，不能由操作者代替机器人批准。

**Blocked by:** 04 — 支持私聊、群聊文本消息与历史记录

**Status:** ready-for-human

- [x] 用户可以向尚未成为好友的普通用户或机器人发送好友申请
- [x] 普通用户可以从通知区域同意或拒绝发给自己的好友申请
- [x] 发给虚拟机器人的申请保持待处理，直到被测插件调用对应 action
- [x] 好友关系只有在接收方同意后建立，拒绝不会建立关系
- [x] 当前用户可以删除自己的好友并产生正确关系变化事件
- [x] 当前用户可以设置只对自己生效的好友备注，不修改对方资料昵称
- [x] 当前用户可以通过嵌套右键菜单戳一戳好友或机器人
- [x] 无关系或能力不支持时，操作返回明确原因且不产生部分状态
