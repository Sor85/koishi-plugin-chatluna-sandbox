# 15 — 通过 MCP 执行好友和群组交互

**What to build:** 外部测试控制器可以通过领域化工具，以明确普通用户身份执行好友、群组和用户侧申请操作。所有行为复用 WebQQ 的权限、关系和事件规则，不提供原始任意 OneBot action 入口。

**Blocked by:** 07 — 支持群组申请与角色权限操作；14 — 通过 MCP 发送消息并等待结果

**Status:** resolved

- [x] `perform_friend_action` 覆盖好友申请、审批、删除、备注和戳一戳
- [x] `perform_group_action` 覆盖入群、邀请、退群、踢人、管理员、群名称、群名片和群内戳一戳
- [x] `handle_request` 只能处理普通用户视角下有权处理的申请
- [x] 发给虚拟机器人的申请不能由 MCP 代替机器人处理
- [x] 所有交互要求 `operatorId` 和幂等 Key，并在执行时检查真实 QQ 权限
- [x] 相同幂等调用不会重复产生操作，不同参数复用 Key 会返回冲突
- [x] 成功操作返回受影响实体、场景版本和事件游标
- [x] 失败操作返回稳定错误码、可重试信息和恢复建议且不产生部分状态

## Answer

MCP 领域工具直接调用统一操作者模型下的好友与群组服务，复用现有 QQ 权限校验，并增加幂等冲突、机器人申请隔离和稳定错误结构。
