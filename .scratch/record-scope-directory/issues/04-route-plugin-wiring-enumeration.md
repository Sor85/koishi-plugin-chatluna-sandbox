# 04 — 插件装配的三处枚举改走记录域目录

**What to build:** 插件装配里三处「遍历全部记录域」的代码都经由记录域目录，「谁是全部记录域」不再留第二个答案。

三处分别是：预设运行时快照的目标解析（遍历全部沙盒场景，只在恰好一个记录域能证明归属时才认），模型请求采集器的候选集合（每个记录域的记录库与思考中的目标），用量事件关联时的记录库集合（主环境、未归属与各 AI 测试空间的记录库）。

这三处与联邦读取共享的恰好是「谁是全部记录域」这一件事，形态不同——它们是纯读取扇出、不分页、不合并，因此只用「列出记录域」而不用联邦读取。用量事件那一处需要未归属，因此用完整清单；另两处只看拥有场景的记录域。

只收一半会让旧枚举写法留在装配里被下一个人照抄，因此本票与调用点迁移同批完成。用户看不到任何变化。
