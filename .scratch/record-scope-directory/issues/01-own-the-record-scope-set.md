# 01 — 记录域目录 module 与它的行为断言

**What to build:** 「谁是全部记录域」变成一个可以单独问的 module，跨记录域读一次、按顺序查找第一个命中、逐个记录域各执行一次这三种行为可以被单独驱动。

记录域分两类：拥有沙盒场景的（主模拟 QQ 环境与各 AI 测试空间）与未归属的（只有模型请求库、没有场景），用可辨识联合表达而不是可选字段。清单顺序固定为主模拟 QQ 环境、各 AI 测试空间按创建序、未归属在末尾——「先查主环境再逐个找」这一语义由该顺序表达，查找不再收「从哪开始」的参数。

联邦读取只要求页上四个字段：记录数组、是否还有更多、当前最早游标、容量摘要。两种记录页的实质差异由调用方以两个参数声明：时间相同时的第二排序键破平函数，以及只在第二排序键跨记录域全局可比时才提供的续页游标。每页条数的上限由调用方先夹紧再传入。

AI 测试空间服务与未归属记录库在构造入参里保持可选，缺席就是清单里少一个成员。判空在构造时吸收一次，之后不再出现。

任何调用点都不动。界面、Console 端点与测试控制端点的行为完全不变，本票是纯新增。

**Blocked by:** None — can start immediately.
