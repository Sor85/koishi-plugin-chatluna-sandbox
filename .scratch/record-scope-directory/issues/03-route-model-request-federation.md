# 03 — 模型请求的联邦读取改走记录域目录，并收回合并函数的公开导出

**What to build:** 模型请求页在「全部」范围下的列表与详情经由记录域目录，「加载更多」继续可用，未归属仍然只能显式指定才读到。

联邦列表改用记录域目录，第二排序键声明为记录标识，并声明续页游标——模型请求的时间与标识组合跨记录域全局可比，WebQQ 的「加载更多」正在使用它，因此这条路必须继续给出续页游标。测试控制端点的模型请求列表同样改走记录域目录，两处不再各写一遍枚举。

「全部」范围排除未归属这条规则从调用点消失，因为记录域目录的联邦读取本来就只遍历拥有场景的记录域。显式指定未归属的读取路径不变。

「全部」范围下的详情改用按顺序查找，与调试记录同一条语义：未命中返回空值，故障原样抛出。

合并函数不再公开导出，收进记录域目录内部。它今天被两个调用点直接使用，而这两个调用点正是本票要改走 module 的——留着导出等于留一条绕过 module 的路。
