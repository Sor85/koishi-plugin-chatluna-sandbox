# 03 — 建立单一群聊与成员关系生命周期

**What to build:** 让每个群组只有一个逻辑群聊，所有当前群成员观察同一份历史。成员关系决定访问和操作权限，退群、踢人和重新入群不再为成员与机器人组合创建或删除不同的底层群会话。

**Blocked by:** 01 — 统一参与者目录与操作者合同

**Status:** ready-for-agent

- [ ] 每个群组只存在一个由群组唯一确定的逻辑群聊，不包含固定用户端或机器人端
- [ ] 当前群成员可以看到同一个群聊入口和同一份历史，机器人操作者不会看到重复群会话
- [ ] 退群或被踢后参与者失去群聊读取和发送权限，但群聊及已有历史继续保留
- [ ] 重新入群后参与者恢复对原群聊和历史的访问，不创建新的群聊 ID
- [ ] 群主、管理员和普通成员权限在用户与机器人参与者之间保持一致
- [ ] 显式删除群组会清理对应群聊、消息、申请和媒体引用
