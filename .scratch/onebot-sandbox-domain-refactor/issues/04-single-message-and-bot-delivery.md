# 04 — 实现消息单份存储与机器人事件投递

**What to build:** 让聊天消息在逻辑会话中只保存一次，并将消息存储与机器人事件接收分离。发送者始终是当前操作者，接收机器人根据私聊对端或当前群成员动态推导，同一消息可以独立投递给多个机器人而不复制历史。

**Blocked by:** 02 — 建立稳定私聊与好友关系生命周期；03 — 建立单一群聊与成员关系生命周期

**Status:** ready-for-agent

- [ ] 文本、媒体、回复和戳一戳消息只记录作者参与者与逻辑会话，不保存消息级机器人归属
- [ ] 普通用户或机器人发送消息时，消息作者始终等于 `operatorId`
- [ ] 用户向机器人私聊只向对端机器人派发事件，普通用户之间私聊不产生机器人事件
- [ ] 群消息向所有符合条件的机器人分别派发，发送机器人不接收自己的入站事件，其他机器人仍正常接收
- [ ] 每次事件投递能够通过 `recipientBotId` 区分目标机器人，并与同一个消息 ID 关联
- [ ] 消息分页、回复引用、媒体读取和消息方向在单份存储下保持正确
