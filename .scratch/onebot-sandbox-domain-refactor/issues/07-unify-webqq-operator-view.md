# 07 — 统一 WebQQ 当前操作者视角

**What to build:** 让 WebQQ 只依赖一个当前操作者参与者 ID，并从该身份推导全部列表、权限和消息表现。普通用户和机器人切换后应获得完全一致的工作台行为，同时保持现有 WebQQ 视觉、布局、动画、菜单和响应式交互不变。

**Blocked by:** 04 — 实现消息单份存储与机器人事件投递；06 — 收紧 Console RPC 与未来 MCP 控制合同

**Status:** ready-for-agent

- [ ] WebQQ 只保存 `currentOperatorId`，不读取或迁移旧当前用户字段，也不存在普通用户代理状态
- [ ] 切换到普通用户或机器人后，最近、好友、群组、通知和当前会话都按该参与者的关系与成员资格刷新
- [ ] 用户和机器人操作者拥有一致的群权限判断、右键菜单、好友申请与群申请处理行为
- [ ] 当前操作者发送的消息始终位于右侧并使用强调色，对端消息始终位于左侧
- [ ] 普通用户、机器人和群组头像样式只由参与者或会话种类决定，不因当前操作者种类发生泄漏
- [ ] 操作者切换、会话选择、聊天输入、右侧信息栏和 ChatLuna 状态在 Chrome 与 Firefox 中保持现有布局和动画
