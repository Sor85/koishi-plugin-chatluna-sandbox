# 01 — 统一参与者目录与操作者合同

**What to build:** 将普通用户和虚拟 OneBot 机器人统一为带明确种类的参与者，并让当前操作者成为所有真实交互的唯一身份来源。环境管理继续作为不产生参与者事件的静默测试准备操作，机器人运行时则继续使用真实 `selfId`。这是宽范围机械重构工单，需要同步切换所有现有调用方，而不是保留旧字段兼容层。

**Blocked by:** None — can start immediately

**Status:** ready-for-agent

- [ ] 场景、工作区和公开控制合同只暴露统一参与者目录，普通用户与机器人资料可通过参与者种类可靠区分
- [ ] 所有真实参与者交互只接受 `operatorId`，消息作者不能与当前操作者分离
- [ ] 环境管理命令不携带操作者身份，机器人实现配置、启用状态和运行时能力只属于机器人参与者
- [ ] `currentUserId`、`actorUserId`、`senderId` 以及用户代理机器人操作者的兼容逻辑全部删除
- [ ] 删除当前参与者后可以选择仍存在的参与者，普通用户和机器人都能承担群主、管理员和普通成员角色
- [ ] 参与者管理、群角色、工作区选择、类型检查和构建测试全部通过
