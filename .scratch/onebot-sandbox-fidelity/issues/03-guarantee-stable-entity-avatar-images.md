# 03 — 保证所有实体拥有稳定头像图片

**What to build:** 让每个普通用户、虚拟 OneBot 机器人和群组始终关联一张真实头像图片，并在没有自定义头像时使用稳定默认图片，同时安全处理媒体去重和回收。

**Blocked by:** 02 — 将自定义头像导入受管媒体

**Status:** ready-for-agent

- [ ] 新建普通用户、机器人和群组时，即使未提供头像也会关联可显示的默认图片
- [ ] 默认图片由实体类型和稳定 ID 决定，同一实体在刷新、导入导出和重启后保持一致
- [ ] 修改用户昵称、机器人昵称或群名称不会改变默认头像
- [ ] 不同实体类型或稳定 ID 不会因名称相同而错误共享身份头像
- [ ] 内容相同的自定义头像在媒体存储中去重
- [ ] 替换头像时仅在旧媒体没有任何剩余引用后回收旧内容
- [ ] 删除实体、场景或其他媒体引用时执行同样的引用感知回收规则
- [ ] 多实体共享同一媒体时，替换或删除其中一个实体不会破坏其他实体头像
- [ ] WebQQ 中所有用户、机器人和群组头像入口均能显示真实图片而非名称首字回退
- [ ] 通过沙盒领域 seam 和媒体 Adapter 测试默认图片稳定性、去重、共享引用及最终引用回收
- [ ] 运行针对性测试、项目测试、类型检查和完整构建并全部通过
