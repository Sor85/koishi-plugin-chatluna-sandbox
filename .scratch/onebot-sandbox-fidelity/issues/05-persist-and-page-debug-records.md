# 05 — 持久化并分页 OneBot 调试记录

**What to build:** 将每个测试空间的 OneBot 调试记录作为独立测试证据持久化，并提供稳定的新到旧序列游标分页、容量回收和可恢复的游标过期错误。

**Blocked by:** 04 — 统一 OneBot 机器人动作记录

**Status:** resolved

- [x] 调试记录独立于场景 JSON、场景导出和短期 MCP 事件缓冲保存
- [x] 内存和数据库 Adapter 满足同一个调试记录持久化 Interface
- [x] 插件重启后，进行中、完成和失败空间的既有调试记录仍可查询
- [x] 每个空间使用独立、单调递增且不会因删除旧记录而复用的 sequence
- [x] 列表默认按新到旧返回 50 条，并允许调用者设置不超过 200 的页面大小
- [x] 分页响应提供稳定的后续游标和是否仍有更多记录的信息
- [x] 页面之间插入新 action 时，继续翻页不会重复或跳过原分页窗口中的记录
- [x] 每个空间最多保留 5000 条记录或 50 MiB 完整内容，达到任一上限时优先回收最旧记录
- [x] 游标指向已回收历史时返回 `cursor_expired` 和当前最早可用游标
- [x] 删除测试空间时，其独立调试记录按空间生命周期正确清理
- [x] 通过 MCP seam 覆盖重启恢复、并发插入分页、条数回收、容量回收和游标恢复
- [x] 运行针对性测试、项目测试、类型检查和完整构建并全部通过
