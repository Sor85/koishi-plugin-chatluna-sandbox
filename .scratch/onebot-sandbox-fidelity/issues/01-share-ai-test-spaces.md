# 01 — 让 AI 测试空间属于 Sandbox 实例

**What to build:** 让 AI 测试空间成为当前 Sandbox 实例的共享测试资源，使凭证轮换不再隐藏已有空间，同时继续严格执行凭证 Scope 和 WebUI 接管规则。

**Blocked by:** None — can start immediately

**Status:** resolved

- [x] 使用一个有效凭证创建的空间，可以被另一个有效凭证发现和读取
- [x] 凭证身份不再参与空间所有权或可见性判断
- [x] `read`、`interact`、`manage` 和 `debug` Scope 继续分别限制对应操作
- [x] WebUI 接管空间后，所有 MCP 修改操作均被拒绝，读取行为仍按 Scope 执行
- [x] 完成、失败和已接管空间在插件重启后保持状态并可由新凭证发现
- [x] 当前数据库中已持久化的空间在变更后仍可读取，不因删除旧所有权概念而丢失
- [x] 旧凭证归属字段和依赖它的过滤逻辑从权威模型中移除，不保留长期双模式
- [x] 通过测试空间 seam 覆盖跨凭证访问、Scope 拒绝、接管阻断和数据库恢复
- [x] 运行针对性测试、项目测试、类型检查和完整构建并全部通过
