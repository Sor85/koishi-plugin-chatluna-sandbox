# 09 — 补齐群消息表情回应交互

**What to build:** 在 WebQQ 中完整展示并操作已有群消息表情回应，让普通用户和机器人以各自真实通道添加或取消回应，同时保持 NapCat 与 LLOneBot 的协议差异可观察。

**Blocked by:** None — can start immediately

**Status:** ready-for-agent

- [ ] 群消息使用 TIM 风格 reaction chip 展示表情图片、已知回应者头像叠层和总人数
- [ ] 多个 emoji 回应可以同时展示，并随场景状态更新而正确聚合
- [ ] 群消息右键菜单提供“贴表情”入口，私聊消息不显示主动回应入口
- [ ] 选择器提供可维护的完整本地 OneBot/QFace 目录、常用区和搜索
- [ ] 点击选择器中的表情可以添加当前操作者回应，再次选择可以取消
- [ ] 点击已有 chip 可以快速切换当前操作者自己的回应，不影响其他参与者
- [ ] 普通用户操作使用用户交互通道，不产生虚假的机器人 action
- [ ] 机器人操作调用真实 `set_msg_emoji_like`，并保留能力禁用、成功和错误动作记录
- [ ] NapCat 与 LLOneBot 对群消息回应的支持和错误行为均通过各自实现配置验证
- [ ] 选择器和 chip 支持键盘操作、正确点击区域，并在窄屏下不溢出聊天工作区
- [ ] 通过沙盒领域 seam 和 WebQQ 工作区 seam 覆盖添加、取消、多参与者、私聊拒绝和能力禁用
- [ ] 使用 Ego Browser 验证 Chrome、Firefox、桌面、窄屏和明暗主题，并清理浏览器临时文件
- [ ] 运行针对性测试、项目测试、类型检查和完整构建并全部通过
