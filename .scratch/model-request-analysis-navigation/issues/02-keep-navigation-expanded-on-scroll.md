# 02 - 右侧滚动不再自动折叠左侧导航

**What to build:** 模型请求分析页右侧卡片区域滚动时，左侧分类保持用户当前设置的展开/折叠状态；仍然跟随高亮当前条目并将其滚入左侧可视区。

**Status:** resolved

- [x] 删除右侧阅读探针触发的分类自动折叠
- [x] 保留分类标题手动展开/折叠
- [x] 保留当前条目高亮和左侧列表自动跟随
- [x] 更新回归测试
- [x] 通过定向测试和类型检查

## Answer

滚动监听现在只计算右侧当前证据条目，用于高亮并滚动左侧对应项，不再写入左侧分类折叠集合。左侧分类只会在用户点击标题时改变展开状态，切换模型请求时恢复默认全部展开。

验证：`yarn vitest run tests/model-request-analysis.test.ts tests/evidence-locator.test.ts`（50 项通过），`yarn typecheck` 通过。

## Comments

用户反馈：模型请求-分析页面右侧卡片区域下滑时，左侧不要再自动折叠。
