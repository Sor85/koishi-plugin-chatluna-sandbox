# 01 - 改为单一吸顶分类导航

**What to build:** 删除分析页滚动边界处的浮动导航副本，用单一吸顶导航展示分类，并按右侧当前分类自动折叠已越过的分组。

**Status:** resolved

- [x] 删除 fallback 导航 DOM、状态和样式
- [x] 左侧导航在详情滚动容器内保持可见
- [x] 当前分类变化时折叠已越过分组并展开当前及尚未读到的分组
- [x] 左侧 Variables 与 Response 顺序对齐右侧卡片
- [x] 具体卡片变化时高亮并自动滚动左侧对应条目
- [x] 当前条目在列表边界仍完整可见
- [x] 保留分类标题手动折叠
- [x] 通过定向测试、类型检查和浏览器验证

## Answer

分析页已改为单一 sticky 左侧导航。右侧阅读探针进入新分类时，只折叠实际已经越过的分类；尚未读到的分类保持展开。左侧顺序调整为 System、User、Variables、Response、Assistant、Tool（空分组隐藏）。阅读探针会继续追踪具体卡片，高亮并仅滚动左侧导航到对应条目；上下安全间距与底部留白确保当前条目完整显示。真实页面验证了 User、Variables、Response、Tool、groupShutList、列表中段、最后一项及反向滚动，全程只有一份导航且无控制台错误。全量 115 个测试文件、645 项测试、最新定向 24 项测试、类型检查和生产构建通过。

## Comments

用户反馈滚动到头后会出现第二套列表，并要求分类标题常驻、右侧进入下一分类时依次折叠已越过分类。
