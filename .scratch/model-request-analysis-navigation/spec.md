# 模型请求分析导航滚动行为

## Problem

模型请求分析页在原左侧导航离开视口后会创建一份 fixed 导航副本。滚动到边界时用户会看到第二套分类列表，且副本与原导航使用两套折叠状态。

## Solution

分析页只保留一份左侧分类导航。导航在模型请求详情滚动容器内吸顶；右侧阅读探针只追踪具体卡片，自动高亮并滚动左侧对应条目，不改变分类的展开/折叠状态。左侧顺序对齐右侧阅读顺序，将 Variables 放在 User 后、Response 放在 Variables 后。条目跟随滚动保留上下安全间距，确保当前条目完整可见。分类标题由用户手动切换折叠状态。

## Acceptance Criteria

- 页面不存在额外的 fixed/fallback 分类列表
- 左侧单一导航在详情滚动期间保持可见
- 右侧上下滚动时不自动展开或折叠任何左侧分类
- 用户手动设置的分类展开/折叠状态在滚动期间保持不变
- 左侧顺序为 System、User、Variables、Response、Assistant、Tool（隐藏空分组）
- 右侧滚动到具体卡片时，左侧对应条目高亮并自动进入可视区
- 当前条目上下保留安全间距，列表末端也能完整显示
- 分类标题点击仍可独立展开或折叠
