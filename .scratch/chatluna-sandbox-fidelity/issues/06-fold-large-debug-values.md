# 06 — 安全折叠调试记录中的大型值

**What to build:** 在保留完整调试证据的同时，默认折叠动作参数和结果中的大型 Base64 内容，避免 MCP、Console 和 WebUI 列表被超大文本淹没，并允许授权调用者显式读取单条完整记录。

**Blocked by:** 05 — 持久化并分页 OneBot 调试记录

**Status:** resolved

- [x] 调试持久化仍保存动作参数、成功结果和错误上下文中的完整原始值
- [x] 任意字段中超过 8 KiB 的 Base64 类内容都会按内容识别并折叠，而非依赖固定字段名
- [x] 折叠摘要包含 encoding、可识别的 MIME、字符数、估算字节数和 SHA-256
- [x] 普通列表、过滤结果和 `wait_for_onebot_action` 永远不展开大型值
- [x] WebUI 与 Console RPC 使用相同摘要结构，不自行实现第二套折叠规则
- [x] 单条记录详情可按记录 ID 查询，并仅在显式设置 `includeLargeValues` 时展开完整值
- [x] 不允许通过列表参数批量展开大型值
- [x] 50 MiB 空间上限按完整持久化内容计算，而不是按折叠后的响应大小计算
- [x] 非 Base64 长文本继续遵守既有文本脱敏和长度保护规则，不被误报为 Base64
- [x] 通过 MCP seam 覆盖嵌套值、不同字段名、MIME 推断、摘要哈希、显式展开和容量统计
- [x] 运行针对性测试、项目测试、类型检查和完整构建并全部通过
