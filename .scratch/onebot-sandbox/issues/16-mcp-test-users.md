# 16 — 让 MCP 自主准备和释放测试用户

**What to build:** 持有 `provision` 权限的外部 AI 可以自主创建具备测试所需资料、好友关系、群成员身份或管理员权限的测试用户，并在测试结束后释放自己的用户。测试用户是普通 QQ 用户，不是机器人或绕过权限的特殊身份。

**Blocked by:** 15 — 通过 MCP 执行好友和群组交互

**Status:** ready-for-agent

- [ ] `provision_test_user` 支持服务端生成数字 QQ ID 或使用未占用的指定数字 ID
- [ ] 创建请求可以设置资料、好友关系、群成员关系和管理员角色
- [ ] 群主测试可以创建由测试用户担任群主的新测试群
- [ ] 创建测试用户不能静默转移既有群组的群主身份
- [ ] 测试用户记录创建凭证、可选测试关联标识和 5 至 1440 分钟 TTL
- [ ] 默认 TTL 为 60 分钟，到期后静默清理并递增场景版本
- [ ] `release_test_user` 只能清理当前凭证创建的测试用户且不需要两步确认
- [ ] 创建和释放要求幂等 Key 与预期场景版本
- [ ] 创建后的测试用户可以立即通过 `interact` 工具执行真实权限操作
