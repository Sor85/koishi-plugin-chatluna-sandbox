# 05 — 支持富媒体消息与安全媒体存储

**What to build:** 用户可以在 WebQQ 会话中发送图片、文件、语音和视频等常见媒体，媒体二进制由插件文件目录管理，场景只保存安全引用和元数据。消息历史能够稳定展示媒体，重置和清理不会留下不受管理的文件。

**Blocked by:** 04 — 支持私聊、群聊文本消息与历史记录

**Status:** ready-for-agent

- [ ] WebQQ 可以选择并发送图片、文件、语音和视频媒体
- [ ] 媒体消息生成对应的 Koishi 消息元素和 OneBot 原始消息段
- [ ] 场景状态只保存媒体标识、类型、名称、大小和安全引用
- [ ] 媒体二进制不写入 Koishi Database 的结构化场景记录
- [ ] 消息历史能够在重新进入会话后继续展示有效媒体引用
- [ ] 不支持的 MIME、超出限制的媒体和无效引用返回明确错误
- [ ] 内存模式重置或重启会清理临时媒体
- [ ] 引用消失后的无主媒体按统一清理策略删除
