# 02 — 复刻 WebQQ 主工作台与当前用户切换

**What to build:** 将 WebQQ 主页面按 onebot-webqq 的视觉和交互语言使用 React、Tailwind CSS 与 shadcn/ui 重写，并作为铺满 Koishi 内容区域的工作台使用。用户可以在多个普通用户之间切换，当前用户和当前视图只保存在浏览器本地，不改变共享模拟 QQ 环境。

**Blocked by:** 01 — 建立最小可运行沙盒闭环

**Status:** ready-for-agent

- [ ] 工作台具有与视觉基线一致的导航、会话列表、聊天区和资料区域结构
- [ ] 页面从 Koishi 左侧入口打开，不使用胶囊、浮窗或弹出页
- [ ] 根容器位于活动栏右侧、填满可用区域且不产生文档级横向滚动
- [ ] 用户可以从用户目录中选择当前用户，页面立即切换到该用户的可见视角
- [ ] 当前用户、活动会话和当前视图按浏览器独立保存，不写入共享场景
- [ ] 外观选项来自 Koishi 插件全局配置，不允许浏览器形成另一套权威主题配置
- [ ] 右键菜单等通用交互使用具备键盘与无障碍语义的 shadcn/ui 组件
- [ ] 关键桌面和窄屏布局在 Chrome 与 Firefox 中均可使用
