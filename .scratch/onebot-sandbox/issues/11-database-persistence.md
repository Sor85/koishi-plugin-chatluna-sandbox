# 11 — 增加 Koishi Database 可选持久化

**What to build:** 允许管理员选择默认内存模式或 Koishi Database 持久化模式。内存模式保持一次性和可重置，Database 模式在插件重启后恢复完整模拟 QQ 环境及媒体元数据，但不会把临时运行状态误当成持久业务数据。

**Blocked by:** 09 — 实现 NapCat、LLBot 私有接口与能力覆盖

**Status:** ready-for-agent

- [ ] 默认配置使用服务端内存作为唯一真实状态
- [ ] 内存模式重启插件后恢复默认场景
- [ ] 启用 Database 后，用户、机器人、群组、关系、消息和能力覆盖可以跨重启恢复
- [ ] Database 只保存媒体元数据和引用，不保存媒体二进制
- [ ] 事件缓冲区、幂等缓存、确认令牌和调试记录不会从 Database 恢复
- [ ] 数据库服务未安装或暂不可用时，插件给出明确状态且不误报已持久化
- [ ] 内存与 Database 模式使用同一测试控制服务和领域语义
- [ ] 持久化模式切换、重启恢复和默认场景重置均有集成测试
