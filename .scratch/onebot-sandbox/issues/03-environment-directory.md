# 03 — 管理模拟 QQ 环境目录与默认场景

**What to build:** 让管理员通过 WebQQ 工作台静默管理模拟 QQ 环境中的普通用户、虚拟 OneBot 机器人和群组，并可以恢复开箱即用的默认场景。管理行为只准备测试数据，不代表 QQ 参与者行为，也不向被测插件发送运行时事件。

**Blocked by:** 02 — 复刻 WebQQ 主工作台与当前用户切换

**Status:** ready-for-agent

- [ ] 管理员可以创建、编辑和删除普通用户，所有 QQ ID 使用字符串表示
- [ ] 管理员可以创建、编辑、启用、停用和删除虚拟 OneBot 机器人
- [ ] 每个机器人可以独立选择 NapCat 或 LLBot 实现配置
- [ ] 管理员可以创建、编辑和删除群组及其初始成员关系
- [ ] 默认场景包含可立即验证私聊、群聊、关系申请和群权限的参与者
- [ ] 环境管理变更不产生 Koishi Session、OneBot 原始事件或聊天通知
- [ ] 删除实体时引用关系被一致清理，不留下无效会话或成员记录
- [ ] 重置默认场景后 WebQQ 从服务端重新取得完整状态
