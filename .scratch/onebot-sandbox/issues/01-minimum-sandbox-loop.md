# 01 — 建立最小可运行沙盒闭环

**What to build:** 提供一个可安装、可启动、可验证的最小 OneBot Sandbox。用户能从 Koishi 控制台进入页面，以预置普通用户向预置虚拟 OneBot 机器人发送文本；被测插件收到标准 Koishi Session 后产生的回复会返回同一会话。该闭环同时建立共享测试控制服务、内存场景以及后续 Ticket 共用的测试、类型检查和构建基线。

**Blocked by:** None — can start immediately

**Status:** ready-for-agent

- [ ] 插件可以在 Koishi 中安装、启用和停用，且未连接真实 QQ 账号时仍能启动
- [ ] 默认内存场景至少包含一个普通用户、一个虚拟 OneBot 机器人和一个可用私聊会话
- [ ] 用户发送文本后，被测插件收到包含正确用户、机器人和会话身份的标准 Koishi Session
- [ ] 被测插件的文本回复会写入同一服务端场景并显示在会话中
- [ ] WebUI 作为原生 Vue 控制台页面通过 Koishi 左侧导航进入并正确挂载和卸载
- [ ] 共享测试控制服务是消息闭环的唯一领域入口，WebUI 不维护独立场景副本
- [ ] 建立可运行的测试、类型检查和生产构建命令并全部通过
- [ ] 最小页面在 Chrome 和 Firefox 中可访问，控制台无运行时错误
