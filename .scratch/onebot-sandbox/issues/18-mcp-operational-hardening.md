# 18 — 完善 MCP 限流、错误与脱敏调试记录

**What to build:** 完成 MCP 对外测试能力的运行安全和诊断闭环。管理员可以配置有限的按凭证限流，外部测试控制器获得稳定结构化错误，具备 `debug` 权限的调用者可以读取脱敏 OneBot 与 MCP 调用记录，而任何 MCP 故障都不会影响 WebQQ。

**Blocked by:** 12 — 提供 OneBot 调试工作台；15 — 通过 MCP 执行好友和群组交互；17 — 提供 MCP 环境管理与场景导入导出

**Status:** ready-for-agent

- [ ] 查询、变更、等待和上传按测试凭证执行可配置且不能无限的速率与并发限制
- [ ] 超限返回稳定错误码和建议重试时间
- [ ] 所有预期业务失败包含稳定错误码、可重试标志、恢复建议、场景版本和 trace 标识
- [ ] 协议解析错误使用 MCP 协议错误，未预期异常不向客户端泄露堆栈
- [ ] MCP 调用记录使用默认 500 条的有界内存缓冲区并与 OneBot 调试记录分离
- [ ] 调用记录包含凭证名称、真实来源 IP、工具、测试关联、耗时、结果和受影响实体
- [ ] Bearer Token、媒体 Base64、TLS 私钥和敏感配置不会进入日志或调试结果
- [ ] `debug` 权限可以分别读取和清理 OneBot 与 MCP 调试记录
- [ ] MCP 监听器、认证、日志或限流组件失败时 WebQQ 和沙盒主体继续工作
- [ ] 27 个 MCP 工具、Resources、权限发现和安全边界完成端到端验收
