# 17 — 提供 MCP 环境管理与场景导入导出

**What to build:** 持有 `manage` 权限的测试控制器可以原子准备或替换模拟 QQ 环境，并通过版本化 JSON 导入导出可复现的测试场景。删除、重置、清空和导入等破坏性行为需要绑定参数与场景版本的两步确认。

**Blocked by:** 11 — 增加 Koishi Database 可选持久化；13 — 提供安全的 MCP 只读端点；16 — 让 MCP 自主准备和释放测试用户

**Status:** ready-for-agent

- [ ] `apply_environment_changes` 可以原子创建或更新既有用户、机器人、群组、关系和能力覆盖
- [ ] 管理操作静默执行，不生成 QQ 参与者事件
- [ ] `prepare_destructive_action` 返回绑定凭证、工具、参数和场景版本的 60 秒一次性令牌
- [ ] 删除既有实体、重置、清空和导入缺少有效确认令牌时不会执行
- [ ] `export_scene` 生成独立版本化 JSON，并排除媒体二进制、凭证、MCP 配置和调试记录
- [ ] `import_scene` 在修改当前状态前完整校验版本、ID、引用、角色、配置和媒体引用
- [ ] 导入失败不会部分修改当前场景，成功后开启新的事件纪元
- [ ] Provision 和 Manage 操作使用预期场景版本防止并发覆盖
- [ ] 场景操作在内存模式与 Database 模式下保持相同外部语义
