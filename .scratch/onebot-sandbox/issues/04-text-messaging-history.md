# 04 — 支持私聊、群聊文本消息与历史记录

**What to build:** 当前用户可以在自己有权访问的好友、机器人和群组会话中发送文本与回复消息，并查看由服务端统一持有的会话历史。不同用户只能看到各自关系和群成员身份允许看到的会话。

**Blocked by:** 03 — 管理模拟 QQ 环境目录与默认场景

**Status:** ready-for-agent

- [ ] 当前用户可以向好友或虚拟 OneBot 机器人发送私聊文本
- [ ] 群成员可以向所属群组发送文本，非成员不能向该群发送消息
- [ ] 用户可以引用已有消息发送回复，历史记录保留回复关系
- [ ] 消息包含稳定的消息、发送者、机器人、会话和时间标识
- [ ] 会话列表和历史记录来自服务端状态，并支持有界分页
- [ ] 不同浏览器选择不同当前用户时，只看到对应身份可见的会话
- [ ] 用户消息生成正确的 Koishi Session 和 OneBot 原始消息事件
- [ ] 被测插件回复写入正确机器人和会话，不串入其他机器人或群组
