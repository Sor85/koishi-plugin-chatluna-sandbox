# 05 — 迁移环境管理并关闭旧 RPC 入口

**What to build:** 让用户、虚拟 OneBot 机器人和群组的创建、编辑与删除也使用统一工作区控制模块，从而完成 WebQQ UI 与 Koishi RPC 的单一传输 seam。

**Blocked by:** 04 — 迁移消息、媒体、历史与公告命令

**Status:** ready-for-agent

- [ ] 环境创建表单只负责输入、校验、loading、错误和结构化提交事件
- [ ] 实体编辑与删除表单不再直接调用 Koishi RPC
- [ ] 用户、虚拟 OneBot 机器人和群组管理通过工作区控制模块执行
- [ ] 环境管理成功后当前操作者、会话和四个区域模型使用现有 fallback 规则同步更新
- [ ] 环境管理失败时旧工作区状态和表单内容符合现有行为
- [ ] 除 Koishi 生产适配器外，WebQQ UI 不再直接调用控制台 send 函数或保存 RPC 路由字符串
- [ ] 环境管理测试和 Ego Browser 创建、编辑、删除流程通过
- [ ] 完整类型检查、测试和构建通过
