# 01 — 建立 WebQQ 回归基线

**What to build:** 建立可重复的 WebQQ 浏览器基准，使后续每一次结构迁移都能证明视觉、交互、响应式和控制台状态没有发生变化。

**Blocked by:** None — can start immediately

**Status:** ready-for-agent

- [ ] 使用固定默认场景、当前操作者和活动会话记录基准条件
- [ ] 保存明亮与暗色主题在 1400px、1000px、700px 下的页面截图和关键 DOM 状态
- [ ] 覆盖最近、好友、群组、通知、发送者切换、发送消息、引用、附件、右键菜单、Dialog、Select 和右侧栏交互
- [ ] 记录头像堆叠动画、消息簇、引用样式、戳一戳事件和自定义滚动条的可观察结果
- [ ] 确认基准页面控制台无未处理异常
- [ ] 运行现有类型检查、完整测试和生产构建并记录结果
- [ ] 基准证据保存在本地功能追踪器中且不进入发布包
