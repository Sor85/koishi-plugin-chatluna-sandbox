# 07 — 统一 WebQQ 头像渲染

**What to build:** 使用一个共享头像模块渲染所有普通用户、虚拟 OneBot 机器人和群组，使不同区域继续保持完全一致的身份颜色、fallback 和徽标比例。

**Blocked by:** 06 — 提取工作区布局与跨区域覆盖层

**Status:** ready-for-agent

- [ ] 共享头像模块支持普通用户、虚拟 OneBot 机器人和群组三种身份
- [ ] 图片、首字母 fallback、圆形裁切和加载失败行为与基准一致
- [ ] 虚拟 OneBot 机器人颜色和机器人头部徽标在所有区域按同一比例渲染
- [ ] 群头像颜色继续区别于普通用户和虚拟 OneBot 机器人
- [ ] 最近、好友、群组、聊天顶栏、消息、发送控件、群成员和私聊信息全部迁移到共享头像模块
- [ ] ContextMenu 和 Tooltip 仍由外层区域控制，不进入头像模块
- [ ] 不增加改变现有网格或定位的额外 DOM 包裹层
- [ ] Ego Browser 对照所有头像尺寸和状态，Chrome 与当前基准一致
