# 11 — 提取右侧信息栏

**What to build:** 将群信息、私聊信息、公告和群成员功能迁移为独立右侧信息栏，同时保持响应式显示和所有群组操作不变。

**Blocked by:** 10 — 提取聊天区域

**Status:** ready-for-agent

- [ ] 右侧信息栏只接收 details 只读模型并通过事件表达公告和成员操作
- [ ] 群信息、私聊信息和环境摘要使用现有根元素与视觉结构
- [ ] 群公告添加、删除、loading 和错误状态由右侧信息栏本地管理
- [ ] 群成员搜索、角色标签、头像和右键菜单行为保持不变
- [ ] 当前会话变化只重置现有要求清理的搜索、公告和错误状态
- [ ] 右侧信息栏不自行监听浏览器宽度，其可见性由工作区布局模块决定
- [ ] 主页面不再包含右侧信息、公告和成员列表实现
- [ ] Ego Browser 验证群聊、私聊、宽窄屏和成员操作，完整验证命令通过
