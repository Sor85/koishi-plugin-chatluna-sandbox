# 08 — 提取发送消息控件

**What to build:** 将发送者选择、头像动画、输入、引用、附件和发送反馈迁移为独立发送控件，使该区域可以单独修改和验证而不影响其他页面实现。

**Blocked by:** 07 — 统一 WebQQ 头像渲染

**Status:** ready-for-agent

- [ ] 发送控件只接收 composer 只读模型并通过明确事件表达领域意图
- [ ] 输入文本、选中附件、发送 loading、错误提示和表单清理由发送控件本地管理
- [ ] 当前操作者头像、候选头像、折叠数量和添加参与者按钮保持原有尺寸与顺序
- [ ] 展开、折叠和切换动画保持原有方向、时序和不跳动行为
- [ ] Tooltip 显示位置、右键菜单位置和层级保持不变
- [ ] 创建普通用户或虚拟 OneBot 机器人的 Popover 保留在发送控件中并通过控制模块提交
- [ ] 切换操作者时现有输入和本地状态重置语义保持不变
- [ ] 头像堆叠单元测试、完整验证命令和 Ego Browser 动画验证通过
