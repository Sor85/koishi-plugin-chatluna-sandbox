## 交互基准

`interactions.json` 记录 17 项实际交互，全部通过：

- 最近、好友、群组和消息视图可以互相切换。
- 通知 Popover 可以打开，证据见 `interaction-notification.png`。
- 发送者可切换至测试用户1，并恢复为固定操作者测试用户3。
- 消息可以发送并写入消息流；消息右键菜单和回复预览可以打开。
- 附件可以选择、显示待发送状态并移除；夹具为 `attachment-fixture.txt`。
- 发送者头像右键菜单可以打开，证据见 `interaction-composer-context-menu.png`。
- 机器人编辑 Dialog 和实现配置 Select 可以打开；Select 同时显示 NapCat 与 LLBot，证据见 `interaction-edit-dialog-select.png`。
- 测试群会话和群信息栏可以打开，证据见 `interaction-group-details.png`。
- 整轮交互未观察到未处理的控制台异常。

## 视觉行为契约

以下项目是后续迁移不得改变的可观察契约：

- **参与者头像堆叠：** 当前发送者保持最右侧视觉锚点；候选头像和“添加测试账号”按钮仅向左展开；悬停不改变候选层级；切换动画不带动整条发送胶囊横移。六组矩阵截图保存折叠状态，交互记录保存切换结果。
- **消息簇：** TIM 模式下，同一发送者的连续普通消息合并为首、中、尾簇；系统事件中断消息簇。对应纯逻辑由 `client/message-cluster.ts` 和现有 Vitest 覆盖，浏览器后续对照应检查 `is-cluster-first`、`is-cluster-middle`、`is-cluster-last`。
- **引用消息：** 消息右键“回复”显示发送控件回复预览；发送后引用块保持左侧引用线、标题、单行省略和点击定位高亮。当前浏览器交互已覆盖右键菜单与回复预览，完整回复关系由现有控制服务测试覆盖。
- **戳一戳事件：** 群内戳一戳写入独立系统事件“操作者 戳了戳 目标”，并中断普通消息簇；对应 OneBot `notify/poke` 通知和事件消息由现有群权限测试覆盖。
- **自定义滚动条：** WebQQ 可滚动容器使用 `data-webqq-scrollbar="true"` 和 `.webqq-scrollbar-overlay`；聊天消息区使用主题色滑块，其他区域使用灰色滑块。矩阵 DOM 状态确认消息区 `overflow-y: auto`，浏览器截图保存当前宽度和位置。

本票据不新增 Vue 挂载测试或浏览器测试依赖。规格已将运行中的 WebQQ 路由定义为最高 UI seam；纯逻辑契约继续由现有 Vitest 覆盖，浏览器证据负责记录真实页面的布局、控件和控制台状态。

## 后续票据使用方式

1. 使用同一默认场景、测试用户3 和 Koishi 私聊。
2. 先运行受影响模块的定向测试，再运行完整测试、类型检查和生产构建。
3. 用 Ego Browser 在受影响视口和主题下重复对应交互。
4. 将迁移后截图和 DOM 状态放入当前票据的证据目录，与本目录逐项比较。
5. 依赖警告单独记录；只有新增或改变的警告才视为模块化回归。
