# 03 — 给剩下十三项行为补上可执行 interface

**What to build:** 模型请求区域那十三项「只能靠人在浏览器里点」的行为变成可执行断言。改缩放步进、改拖动阈值、改文件名规则、改缺省符号、改二次确认步骤,测试会当场变红并指出是哪一条判定坏了,而不是等到有人在局域网 HTTP 页面上发现复制按钮没反应。

`assertion-classification.md` 的「副产物」一节列了十三项行为:D 类那 102 条被删断言各自附着「本该由什么 interface 承担」,汇总起来就是这张清单。它们当时没有可执行 interface,判定内联在三个组件的 script 里,唯一的验证手段是人工点击。其中几项的失效形态在开发机上撞不到——剪贴板降级只在非安全上下文触发,拖选守卫只在真的拖了文字之后触发,时区边界只在跨日跨年那一刻触发。

十三项按内聚拆成九个 module:组成图手势、JSON 行状态与手势、详情页签与轨迹模式、正文取文复制下载、概览与用量取词、记录时间格式化、清理二次确认各一个新 module,轨迹账本可见行与搜索并入既有的账本展示 module,自动刷新策略并入既有的自动刷新 module。

触碰 DOM 的三项按 ADR-0075 的办法拆:判定进 module,DOM 机械动作留在视图里由参数注入,注入的形状取最小结构接口而不是 DOM 类型。仍然不引入 jsdom、happy-dom 或组件挂载测试。

界面行为与文案不变。视图侧全部改成从 module 解构出同名 ref 与同名函数,因此模板一行没动的地方仍然一行没动。

## Comments

十三项全部消化。九个 module 的行为测试合计 83 个用例,测试总数 882 → 963,测试文件 133 → 141。

**两处偏差,都是为了不把既有的成本结构改坏。**

第一处:账本搜索原先是两级 computed——可搜索文本只随轨迹变化,静音只随查询变化。第一版把两级合成了一个 `buildModelRequestTrajectorySearchMutes(rows, query, describeRow)`,结果每次按键都要为每一行重新 `toLocaleLowerCase` 五个字段,`model-request-read-cost.test.ts` 当场变红。这条守卫是对的,拆回两段:`buildModelRequestTrajectorySearchTexts` 折叠文本,`buildModelRequestTrajectorySearchMutes` 只做判定,视图仍是两级 computed。

第二处:`createModelRequestClearConfirm` 的第一版加了一个 `watch(open)`,想让「按 Esc 关闭也退回第一步」成立。测试立刻暴露两件事:同拍内 true→false 的变化会被 watcher 的变更检查折叠掉,而且这个 watcher 本来就不需要——`begin()` 已经把步骤复位,而 `begin()` 是唯一的打开路径。删掉 watcher,把不变量写成「每次打开都从第一步开始」。原描述里「按 Esc 后重新打开会停在确认清理」的说法是我凭空构造的缺陷,原实现没有这个问题。

**五条别处的源码断言变红,处置如下。**

`model-request-read-cost.test.ts` 那条见上,是真问题。剩下四条是 ADR-0073 描述的假红:两条 `formatTime(...)` 与一条 `formatImageSize(...)` 只是函数改了名字,把断言里的标识符跟着改掉;`webqq-preset-workspace.test.ts` 那条断言 `bodyView.value = 'analysis'` 这句赋值存在,改成断言 `showEvidenceAnalysis()`——命名转换比一句裸赋值稳定得多,预设入口落在分析页签这条契约仍然守着。

`webqq-model-request-workspace.test.ts` 里另有两条随之删除:用量格八项标签的顺序断言,以及 `detail.model || '未识别'` 这句写法断言。两者的事实现在都由 `model-request-overview.test.ts` 逐项执行验证,用量格改成断言模板逐格渲染 module 给出的取词结果;模型名称那条只留三条否定式守卫,守住「不得再出现第二份推断」。

**界面行为与文案不变,唯一例外见上。** 记录时间格式化原先对非法时间输出 `NaN-NaN-NaN NaN:NaN:NaN`,改成缺省符号,与相邻的耗时格、计数格一致。这是本轮唯一的真实行为变更,落在清单第十二项「时间格式化与时区边界」的范围内,与新增的边界断言同源,因此不另拆票。其余取词函数的缺省呈现全部与固定点逐字相同:TPS 非有限值、Token 计数缺省、耗时缺省本来就是缺省符号,不是本次引入的。

**没做浏览器验证。** 生产代码只有取词函数改名与状态转换换成命名调用,判定逻辑逐条对照搬移,行为不变;时间格式化换成 `Intl` 是唯一的实现替换,由跨日、跨年、午夜三个边界的断言覆盖。
