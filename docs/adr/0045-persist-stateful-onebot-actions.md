# 有状态 action 必须写入领域状态

沙盒声明为支持的有状态 OneBot action 必须把结果写入沙盒场景，而不是只做权限与存在性校验后返回成功。专属头衔、群禁言状态和消息表情回应都进入群成员与消息模型，使 WebQQ、场景快照、`get_msg` 与群成员查询读到同一份事实。WebQQ 必须展示已有表情回应，并允许普通用户通过用户交互、虚拟 OneBot 机器人通过 `set_msg_emoji_like` 操作未撤回的私聊或群聊消息；消息撤回后已有回应保留为历史事实，但不再允许修改。

只做“确认调用”的实现会让插件和外部测试控制器无法区分“调用链路通了”和“功能真的生效了”，把断言退化为相信机器人的自述回复。沙盒仍不模拟上游实现真实存在但缺少领域模型的资源（例如群相册），这类能力继续声明为 `supported: false` 并给出原因。
