# 将消息撤回建模为生命周期状态

消息撤回是既有消息的生命周期变化，不是新的系统消息，也不与戳一戳等消息事件共用 `event` 字段。消息使用判别联合状态表示可见或已撤回；撤回状态记录撤回者和撤回时间，并在权威场景中保留原始正文、媒体、回复关系、表情回应和 ChatLuna 思考，供 WebQQ 展示与测试复盘。普通 OneBot `get_msg` 和机器人查询仍按真实撤回语义拒绝读取原始内容，已有表情回应保留但不能再修改。

全局 `webQQMarkRecalledMessages` 默认开启且只控制 WebQQ 呈现：开启时保留原气泡并为正文和媒体显示撤回线，ChatLuna 思考保持正常可读但随消息弱化；关闭时隐藏原气泡和思考并显示撤回事件，底层数据不销毁，重新开启后可以恢复展示。撤回成功时仍发出独立的 `message.recalled` MCP 事件和场景变更，使外部测试控制器可以精确等待和断言撤回。
