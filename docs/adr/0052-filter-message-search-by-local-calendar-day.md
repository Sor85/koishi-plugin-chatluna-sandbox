# 按本地自然日筛选聊天记录搜索

聊天记录搜索支持关键词、单日或两者组合。日期选择器采用 shadcn-vue registry 提供的 `Calendar`，并与项目已有的 shadcn-vue `Popover`、`Button` 组合；不得退回原生日期输入，也不得自行实现月份导航、日期网格或键盘交互。Calendar 的 `DateValue` 只存在于 UI 适配层，搜索条件仍持有稳定的本地日历日 `YYYY-MM-DD`。

WebQQ 聊天区域将 `YYYY-MM-DD` 转换为本地零点和次日本地零点对应的 ISO 时间，再通过共享搜索输入传递给控制服务。日期值不能先转为 JavaScript `Date` 再生成搜索字符串，否则 UTC 换算可能让选中的日历日偏移。

服务端使用 `createdAtStart <= createdAt < createdAtEnd` 半开区间筛选，并在既有会话消息游标扫描内执行日期与关键词组合判断。客户端不得只过滤当前返回页，否则会遗漏该自然日内位于后续分页的消息。

本地日期不能使用 `new Date('YYYY-MM-DD')` 解析，因为该格式按 UTC 解释；也不能固定增加 24 小时得到结束边界，因为夏令时切换日未必等于 24 小时。应以数值年月日创建本地零点，并通过本地日历推进一天。

搜索输入允许关键词为空但日期区间完整；关键词与日期都缺失时返回空结果，不扫描整个逻辑会话。日期边界必须成对出现、可解析且结束时间晚于开始时间。
