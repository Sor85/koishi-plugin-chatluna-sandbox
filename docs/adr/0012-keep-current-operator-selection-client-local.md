# 当前操作者选择按浏览器独立

沙盒场景由所有控制台页面共享，但当前操作者和当前视图只属于各浏览器的界面状态，不在服务端维护全局操作者。每次 WebQQ 操作必须显式携带参与者 ID，使多位管理员能够同时以不同普通用户或虚拟 OneBot 机器人身份测试，并实时观察对同一模拟 QQ 环境造成的变化。

当前操作者离开或被移出当前群组时保持不变，该群会话从其视图消失，并回退到第一个可见会话或空状态；机器人停用时仍保持选中并允许观察，但所有机器人操作均不可用；当前操作者被删除时，依次回退到第一个普通用户、第一个虚拟 OneBot 机器人或空环境。MCP 不共享这项客户端状态，仍由每次调用显式提供普通用户身份。
