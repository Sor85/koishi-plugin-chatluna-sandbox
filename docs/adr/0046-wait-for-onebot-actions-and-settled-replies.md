# 通过事件流等待 OneBot action 与最终回复

OneBot 调试记录并入 MCP 事件流，外部测试控制器用 `wait_for_onebot_action` 等待被测插件真实发起的 action 及其成败，不再轮询 `list_onebot_debug_records`。`wait_for_message` 增加静默期参数，匹配到消息后继续收集同条件消息直到静默，返回最终消息与完整序列。

机器人常先回一条中间消息再给最终结果，只匹配第一条会把“稍等”当成答案；机器人回复文本也可能与 action 实际结果不一致，只有调试记录能证明操作是否真的执行成功。两项等待都复用既有事件游标语义，不引入独立的轮询接口或新的状态存储。
