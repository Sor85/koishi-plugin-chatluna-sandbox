# 通过事件流等待 OneBot action 与最终回复

OneBot 调试记录并入 MCP 事件流，外部测试控制器用 `wait_for_onebot_action` 等待被测插件真实发起的 action 及其成败，不再轮询调试记录列表。匹配成功时直接返回与持久化调试记录同型的规范机器人动作记录和事件游标；`wait_for_message` 使用静默期收集同条件消息，返回最终消息与完整序列。

机器人常先回一条中间消息再给最终结果，只匹配第一条会把“稍等”当成答案；机器人回复文本也可能与 action 实际结果不一致，只有机器人动作记录能证明操作是否真的执行成功。等待仍使用短期事件游标，不与调试记录分页游标或持久化存储混用。
