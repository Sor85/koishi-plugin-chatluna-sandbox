# 高破坏性 MCP 管理操作需要两步确认

清空、重置、覆盖导入及会级联删除既有环境关系或消息的实体删除，必须先生成绑定测试凭证、操作参数和场景版本的短期确认令牌，再携带令牌执行。普通编辑和真实 QQ 用户交互不使用确认令牌。

令牌只能使用一次，并同时承担版本绑定与防重放：场景版本在签发后发生变化即失效，因此执行时不再重复提交 `expectedRevision`，也不叠加 `idempotencyKey`（见 ADR-0022、ADR-0021）。重试必须重新取得令牌——破坏性操作不应当可以盲目重试。

「操作参数」指业务参数：签发时提交的 `arguments` 与实际调用的参数按同一个业务参数指纹比对，调用标注参数不参与（见 ADR-0097）。
