# 使用逻辑会话与单份消息存储

其中「逻辑会话唯一」这一条已被 [ADR-0076](./0076-support-multiple-conversation-instances-per-contact.md) 部分取代：根会话仍然对每对参与者与每个群组唯一，但根会话下可以有多个会话实例。以下原文不改写——当时要求唯一的理由本身有价值，单份消息存储与「关系删除只撤销访问」这两条也仍然成立。

任意两个参与者之间只有一个稳定私聊，每个群组只有一个群聊，逻辑会话不绑定当前操作者或事件接收机器人。聊天消息只保存一份且不携带冗余机器人 ID，同一消息可以向多个虚拟 OneBot 机器人产生独立事件投递；关系删除只撤销会话访问，只有删除参与者或群组才清理对应会话和历史。
