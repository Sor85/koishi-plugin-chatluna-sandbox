# MCP 环境管理使用场景版本控制

修改场景的 `manage` 工具必须提交读取时获得的 `expectedRevision`，当前版本不匹配时拒绝修改并要求客户端重新读取。`interact` 工具不锁定场景版本，而是在执行时根据最新成员关系和权限返回真实业务结果，使环境管理避免并发覆盖，同时保留 QQ 交互的实时语义。

破坏性管理操作在执行时不重复提交该参数：版本在 `prepare_destructive_action` 取得确认令牌时绑定，执行时由令牌校验，版本已变化则令牌失效（见 ADR-0023）。AI 测试空间的生命周期工具管理空间自身而非场景内容，同样不提交场景版本。
