# 毛玻璃表头必须真实覆盖滚动内容

覆盖式或吸顶式表头只有在其绘制区域与对应滚动视口真实重叠时才能使用毛玻璃；仅给位于独立 Grid 行的表头声明半透明背景和 `backdrop-filter`，背后仍是纯色区域，视觉上不会产生雾化。实现此类表头时，滚动视口必须延伸到表头后方，并以等效的顶部内边距和 `scroll-padding-top` 保持首项位置及定位行为；模糊层统一放在无后代的 `::before` 上，避免表头自身形成 Backdrop Root，破坏内部 Popover、Select 等浮层的毛玻璃。验证不得只检查 `backdrop-filter` 的计算值，还必须确认表头与滚动视口存在大于零的几何重叠，并在滚动内容经过表头后方时进行视觉验证。
