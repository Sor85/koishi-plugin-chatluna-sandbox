# 持久化并使用序列游标分页 OneBot 调试记录

OneBot 调试记录作为测试证据独立于沙盒场景持久化，使已完成空间在插件重启后仍可复盘 action、事件和错误。每个测试空间按单调序列保存记录，列表默认从新到旧返回 50 条、单次最多 200 条，并使用独立调试记录游标继续分页；新增记录不会造成翻页重复或遗漏。每空间默认同时受 5000 条和 50 MiB 上限约束，达到任一上限后从最旧记录开始回收，读取已回收位置时返回 `cursor_expired` 和当前最早游标。

调试存储保留完整输入和结果，但任何字段中的 Base64、Data URL 或 `base64://` 内容超过 8 KiB 时，列表、等待结果和常规详情默认只返回编码、MIME、长度与 SHA-256 摘要。完整大值只能通过单条记录详情接口按记录 ID 并显式启用展开后读取，容量上限始终按完整持久化内容计算。
