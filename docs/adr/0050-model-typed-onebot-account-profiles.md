# 使用类型化资料模型支持个人信息卡

普通用户和虚拟 OneBot 机器人的账号资料使用类型化可选字段建模，覆盖当前 NapCat 与 LLOneBot 基线能够表达的资料全集，而不保存或直接展示实现特有的原始 API JSON。账号资料、好友备注、群成员资料和机器人运行资料保持独立语义；WebQQ 个人信息卡可以汇总展示场景中已有的全部信息，但必须标明每项资料所属范围，避免把好友备注、群名片或机器人配置误认为全局账号资料。

所有参与者头像入口都提供右键查看资料，个性签名同时显示在个人信息卡和私聊右侧信息面板。`set_qq_profile` 严格遵循实现配置：NapCat 与 LLOneBot 都可以修改昵称和个性签名，只有 NapCat 接受性别修改；其他资料通过环境管理、MCP 场景准备或场景导入维护，不为方便 WebUI 而虚构 OneBot 写入能力。
