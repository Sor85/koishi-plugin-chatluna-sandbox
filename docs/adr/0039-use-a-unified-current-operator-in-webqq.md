# WebQQ 使用统一当前操作者

WebQQ 工作台只维护一个可为普通用户或虚拟 OneBot 机器人的当前操作者。最近会话、好友、群组、通知、权限判断和消息发送身份始终跟随该参与者，不再提供独立切换当前发送者的能力。

普通用户的交互通过用户操作通道执行；虚拟 OneBot 机器人的交互必须通过 OneBot action 执行，并受机器人启用状态、NapCat 或 LLBot 实现配置及能力覆盖约束。机器人离线时仍可作为当前操作者观察已有状态，但相关操作保持可见且禁用，并明确区分离线、群角色不足和能力缺失。

普通用户和虚拟 OneBot 机器人使用相同的群角色模型，都可以成为群主、管理员或普通成员。机器人发送消息时不向自身派发入站事件，但会向同一会话中的其他机器人派发相应事件。MCP 仍保持普通用户身份边界，不允许通过外部测试控制器切换或冒充机器人。
